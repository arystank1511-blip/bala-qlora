# bala-qlora

Автор проекта — **Арыстан Қабдеш (Arystan Kabdesh)**. Об использовании ИИ — раздел «Авторство и использование ИИ».

Эксперимент с QLoRA для Qwen2.5-1.5B-Instruct: короткие объяснения школьных
тем детям на казахском и русском с учётом возраста и интереса.

## Состояние

Эксперимент завершён 23 октября 2026 года: 3 эпохи, 48 шагов на бесплатном
Colab Tesla T4, 26,4 минуты обучения по журналу Trainer. Адаптер содержит
18 464 768 обучаемых параметров; сохранение, повторная загрузка и генерация
проверены. Все 43 теста прошли локально и в Colab.

На 32 тестовых примерах chrF вырос с 18,88 до 25,09, соблюдение ограничения
длины — с 90,6% до 100%. Это не доказывает правильность содержания:
в ответах есть фактические ошибки, казахский текст часто бессвязен.
Текущий адаптер остаётся исследовательским прототипом.

Подробности: `results/REPORT.md`, критерии качества: `docs/quality_review.md`,
настройки и исходный код запуска: `results/runtime.json` и `results/source/`.
`data/readiness.json` подтверждает готовность данных, а не качество модели.

Датасет: 300 синтетических примеров Claude (150 kk + 150 ru) и 10 исходных
примеров. Редакторская проверка и исправления выполнены с помощью Codex.
Решения и происхождение сохранены в `data/ai_review.jsonl`,
`data/reviewed.jsonl` и `data/seed_review.json`. Черновики сохранены.
Личная ручная проверка и независимая экспертная оценка не заявляются.

## Запуск

Архив обученного адаптера и результаты запуска опубликованы в
[релизе v0.1.0](https://github.com/arystank1511-blip/bala-qlora/releases/tag/v0.1.0).
Базовые веса Qwen в архив не входят и скачиваются отдельно при запуске.

Откройте `notebooks/colab_train.ipynb` в Colab, выберите **T4 GPU** и **Run all**.
Код и данные уже встроены: дополнительная загрузка CSV/ZIP не нужна.
Ноутбук устанавливает библиотеки, проверяет данные, обучает адаптер,
сравнивает его с базовой моделью и предлагает скачать архив результатов.
Доступность бесплатного GPU зависит от Colab. Платный API и публикация
на GitHub для запуска не нужны.

Архив результатов содержит адаптер, график loss, журнал обучения,
метрики, ответы обеих моделей и манифест данных. Сохраните его до отключения
среды. Для повторного обучения используйте новую среду: первая ячейка
не перезаписывает уже существующий проект.

## Данные и воспроизводимость

Проверка исправляет фактические ошибки, формулировки и неподходящие детям
советы. Для каждой строки есть решение keep / fix / drop. Незавершённый
или некорректный импорт сохраняет ранее проверенные данные.

`scripts/prepare_data.py` проверяет поля, язык, длину, возрастные ограничения и
дубликаты. Темы целиком распределяются между train/val/test, включая
переводы. Темы исходных примеров остаются в обучении, поскольку использовались
при подготовке черновиков. В каждой выборке есть оба языка; доли около 80/10/10.

SHA-256-манифест связывает данные, выборки, промпты и карту тем. Обучение
проверяет его и сохраняет с адаптером; оценка требует совпадения манифеста.
Замена выборки требует `--replace-splits` и нового эксперимента.

Команды выполняются из корня проекта:

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/review.py import --input data/review.csv --review-kind ai --reviewer Codex
.\.venv\Scripts\python.exe -X utf8 scripts/prepare_data.py
.\.venv\Scripts\python.exe -X utf8 scripts/train_qlora.py --check-only
.\.venv\Scripts\python.exe -X utf8 scripts/build_colab_notebook.py
.\.venv\Scripts\python.exe -X utf8 -m pytest -q
```

Для последующей человеческой проверки используется `--review-kind human`;
тип и автор новой проверки должны соответствовать фактической работе.

## Отдельные вопросы после обучения

Распакуйте архив результатов в корень проекта: адаптер должен оказаться в
`outputs/adapter`. В той же среде с T4 можно задавать вопросы без нового обучения:

```bash
python scripts/chat.py --lang ru --age 8 --interest футбол --question "Почему мяч подпрыгивает?"
python scripts/chat.py --lang kk --age 8 --interest футбол --question "Доп неге секіреді?"
```

Скрипт использует сохранённый токенизатор, проверяет версию промпта и загружает
базовую модель вместе с адаптером. Базовые веса при первом запуске скачиваются
из Hugging Face; они не входят в архив адаптера. Если ответ упирается в лимит
токенов, выводится предупреждение.

## Метод

Qwen2.5-1.5B-Instruct загружается в NF4 с double quantization. LoRA:
r=16, alpha=32, dropout=0.05 на attention и MLP-проекциях. Обучение:
3 эпохи, lr=2e-4, cosine schedule, эффективный batch=16.
Loss считается только по токенам ответа; промпт замаскирован -100.
Длинные примеры отклоняются, а не обрезаются. Сохраняется лучшая эпоха
по validation loss.

На тесте одна загруженная модель отвечает с выключенным и включённым
адаптером при одинаковых промптах и greedy decoding.

| Метрика | Что измеряет |
|---|---|
| lang_ok | Эвристическое совпадение языка |
| sentences_ok | 2–5 сегментов; цель промпта — 2–4 предложения |
| length_ok | До 60 слов для возраста ≤8, до 90 для старших |
| interest_used | Упоминание интереса по словам и основам |
| chrf | Символьное сходство с эталоном |

Метрики не проверяют достоверность и естественность казахского.
`results/manual_review.csv` — лист для отдельного слепого сравнения A/B.
Незаполненный лист не считается оценкой; ИИ-оценка не считается человеческой.

Для QLoRA нужен CUDA GPU. CPU smoke test на маленькой случайной Qwen
проверяет совместимость кода и сохранение LoRA, а не качество целевой модели.

## Ограничения

Набор небольшой: 300 синтетических примеров и 10 существующих seed-примеров,
первоначальное происхождение которых отдельно не подтверждено. Профили
возраста/интереса служат условиями генерации. ИИ-проверка
может пропускать ошибки. Для детского продукта нужны независимые проверки
содержания и языка. Карта тем уменьшает утечку переводов, но не гарантирует
отсутствия всех смысловых пересечений. Малый тест не доказывает пригодность
модели для использования детьми.
