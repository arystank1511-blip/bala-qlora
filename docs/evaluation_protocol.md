# Протокол оценки bala-qlora

Зафиксирован до получения результатов текущего GPU-эксперимента.

1. Один запуск Qwen2.5-1.5B-Instruct: NF4, LoRA r=16/alpha=32,
   3 эпохи, lr=2e-4, seed=42. Лучший адаптер выбирается по validation loss.
2. Train/val/test: 242/36/32. Темы и переводы не пересекаются между
   выборками; в тесте 16 казахских и 16 русских примеров из 6 групп тем.
3. Вся тестовая выборка оценивается один раз после выбора адаптера.
   Тестовые ответы не используются для повторной настройки этого запуска.
4. Base и finetuned — одна и та же загруженная NF4-модель с выключенным
   и включённым адаптером. Промпты одинаковые, greedy decoding,
   repetition_penalty=1.05, max_new_tokens=320. Достижение лимита записывается
   отдельно; обрезанные ответы не исключаются из метрик.
5. Автоматические показатели: язык, 2–5 сегментов предложений, возрастной
   предел длины, упоминание интереса, chrF относительно одного эталона.
   Цель промпта строже: 2–4 предложения. chrF — мера сходства текста,
   не показатель фактической правильности. Эвристики могут ошибаться.
6. Дополнительная редакторская оценка ИИ проводится вслепую по листу A/B,
   отдельно для каждого языка. Рецензент получает вопрос, возраст, интерес,
   эталон и ответы A/B, но не ключ модели, метрики или журнал обучения.
   Ключ раскрывается после сохранения решений по всем 32 строкам.
7. Для каждого ответа оцениваются фактическая правильность, понятность
   ребёнку указанного возраста, качество целевого языка, соблюдение формата
   и уместность связи с интересом. Вердикт: A, B или =. Явная фактическая
   ошибка или бессвязный ответ важнее формального совпадения с интересом.
   Если оба ответа имеют существенные проблемы и ни один явно не лучше,
   ставится = с описанием проблем. Предпочтение не означает безошибочность.
8. ИИ-оценка записывается отдельно с типом проверки и именем инструмента.
   Исходный незаполненный лист человеческой оценки сохраняется.
   Проверка ИИ не является независимой экспертной или пользовательской.

Небольшой синтетический тест оценивает этот конкретный эксперимент.
Результаты не доказывают безопасность или качество детского продукта,
не измеряют устойчивость к произвольным вопросам и не дают статистически
надёжной оценки для всей совокупности тем. Ухудшения публикуются вместе
с улучшениями.
